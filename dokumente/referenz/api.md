# API-Referenz

Diese Seite liegt im Unterordner `dokumente/referenz` und erscheint deshalb
als ausklappbarer Unterpunkt unter **Dokumente**.

## Endpunkte

| Endpunkt | Methode | Beschreibung |
| -------- | ------- | ------------ |
| `/api/seiten` | GET | Liste aller Seiten |
| `/api/navigation` | GET | Navigationsbaum |

## Beispiel

```
GET /api/navigation
```

> Hinweis: Dies ist eine Beispieldatei. Ersetze sie durch eigene Inhalte.
