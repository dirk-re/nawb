# Hallo Welt

Willkommen im Blog. Dieser Ordner zeigt: Auch ohne eigene `index.md` wird
ein Ordner als Navigationspunkt angezeigt, solange Markdown-Dateien darin
liegen.

## Wie die Navigation entsteht

- Ordner `blog` wird zum Punkt **Blog**
- Diese Datei wird zum Unterpunkt **Hallo Welt**

Sobald weitere `.md`-Dateien in diesem Ordner liegen, erscheinen sie
ebenfalls automatisch.
